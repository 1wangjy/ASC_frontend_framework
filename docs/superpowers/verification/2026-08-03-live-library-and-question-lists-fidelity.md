## 有意差异

参考图中的统计数字 542 / 38 / 497 / 486 是静态演示值。最新实现用当前五条本地演示文献计算出 5 / 3 / 4 / 3；后端返回完整文献集合后会按同一逻辑自动更新。这是实现实时统计所必需的有意差异。

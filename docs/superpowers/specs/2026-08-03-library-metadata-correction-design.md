# 文献属性纠正设计

## 背景

文献列表把“专家评分”错误地建模为文献属性，并同时展示了处理状态和更新时间。实际业务中，专家与 LLM 评分的对象是模型回答；文献只有是否被精选的区别，不存在文献专家分数。

## 页面设计

文献表格保留选择框、文献、DOI、作者、年份、类型和领域标签。删除“专家评分”“处理状态”“更新时间”三列。精选文献在标题旁显示轻量的“精选”标签，不增加独立列，避免表格重新变宽。

## 数据边界

示例文献数据删除 `expertScore`、`statusLabel` 和 `updatedAt`。`expertSelected` 作为布尔值保留，用于精选标签和顶部精选数量。`parsingStatus` 与 `qaIndexed` 作为内部流程状态保留，只用于顶部动态统计和后续后台接口衔接，不作为文献属性列展示。

本次不设计模型回答的专家评分或 LLM 评分；该功能等评分规则明确后单独实现。

## 验收标准

- 文献表格不出现专家评分、处理状态和更新时间。
- 示例文献不包含任何文献专家分数字段。
- 精选文献能以“精选”标签识别。
- 顶部精选、解析和 QA 索引数量继续按数据动态计算。
- 文献搜索、年份筛选、分页与详情选择保持可用。

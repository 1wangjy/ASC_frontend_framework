# 知识图谱同步启动接口设计

## 现状

前端已存在 `/knowledge` 入口页、`/knowledge/explorer` 本地图谱页和 `knowledgeGraphLauncher.js`，但入口使用独立 `fetch`，且没有配置 API 时会直接回退到本地图谱。这绕过了后端启动流程，也没有复用项目 Axios 的统一请求头、错误处理和长请求配置。

## 请求流程

用户点击“进入知识图谱”后，页面立即清空旧错误、禁用按钮，并显示旋转加载图标与“正在进入…”。前端通过 `src/api/graph.js` 发起一次 `POST /api/graph/launch` 同步长请求，等待服务器返回，不轮询，也不自动重试。接口地址可由 `VITE_GRAPH_LAUNCH_API` 覆盖；单次请求超时为 15 分钟。

API 模块复用现有 Axios service，因此继续携带 `X-NEXUS-USER`，并使用统一响应与网络错误拦截。成功响应可使用 `redirectUrl`、`redirect_url` 或 `url` 传递页面地址。地址必须能解析为 HTTP/HTTPS 地址；缺失或危险协议视为失败。

## 跳转与失败

以 `/` 开头且不是 `//` 的地址视为站内路由，使用 Vue Router 跳转；其他 HTTP/HTTPS 地址使用 `window.location.assign` 直接打开。请求失败、响应错误或地址无效时，页面显示用户可读错误，解除按钮禁用，并保留“重试”按钮。每次重试都重新执行一条新的同步请求。

## 验收标准

- 默认点击发起一次 `POST /api/graph/launch`，没有本地免请求回退。
- 请求等待期间按钮禁用并显示“正在进入…”加载状态。
- 成功响应能规范化三种地址字段并安全跳转。
- 同步请求失败后显示错误，按钮恢复且可以再次点击。
- 重复点击已禁用按钮不会发起并行请求。
- `/knowledge/explorer` 路由继续保留，可作为后端返回的站内目标地址。

# 问答首页标题对齐与名称统一设计

## 目标

- 让 ASC 圆标、主标题、副标题和下方问答框共享清晰的视觉中轴。
- 将侧边栏中的“QA 首页”改为“问答首页”。
- 同步移动端页面标题，避免同一页面出现两套名称。

## 设计决定

标题区使用满宽网格容器，并由容器统一负责水平居中。ASC 圆标不再依赖单独的自动外边距；圆内文字使用固定行高，避免字体基线造成轻微上下偏移。主标题仍保留当前宋体风格，但增加极小的光学校正，以抵消中文问号末端留白形成的视觉偏差。

导航名称和首页路由标题都统一为“问答首页”。回答区中用于表达产品身份的“ASC QA”不属于导航名称，本次保持不变。

## 验收标准

- 桌面端 ASC 圆标、标题、副标题与问答框中心线一致。
- 手机端标题区不横向溢出，页面标题显示“问答首页”。
- 侧边栏当前菜单显示“问答首页”。
- 现有问答、文献与知识图谱交互测试继续通过。

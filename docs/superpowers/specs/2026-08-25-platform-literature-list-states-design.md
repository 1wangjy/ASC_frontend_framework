# 数据平台文献库列表状态设计

## 目标

只优化“数据平台 → 文献库管理”的文献列表加载状态、空数据状态、搜索筛选无结果状态和请求失败提示，不改变现有文献功能及后端接口。

## 状态优先级

页面工具栏和“导入 PDF”入口始终保留，列表区域按以下优先级只显示一个状态：

1. 请求进行中：显示“文献加载中...”
2. 请求失败：显示“文献加载失败，请稍后重试”和“重新加载”按钮
3. 请求成功且原始文献数量为零：显示“暂无文献，可通过‘导入 PDF’添加第一篇文献”
4. 原始文献有数据但搜索、类型或年份筛选后为零：显示“未找到符合当前条件的文献”
5. 其他情况：显示现有文献列表、选择控件和分页

## 实现边界

- `DataManagerView.vue` 负责请求状态、错误状态和重新加载动作。
- 新建一个小型展示组件，只根据传入状态渲染对应文案，并在错误状态发出重试事件。
- 不修改搜索、筛选、分页、多选、CRUD、PDF 操作及详情逻辑。
- 不修改 3001、5001、MongoDB、GridFS、`/documents`，不新增依赖。

## 验证

- 聚焦组件测试覆盖加载、真实空库、筛选无结果、请求失败及重试入口。
- 运行前端 build，确认现有页面组件仍可编译。

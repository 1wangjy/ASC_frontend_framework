# 问答首页右侧最近会话栏设计

## 目标

将当前左侧导航中的“最近会话”移入问答首页右侧，形成一个视觉弱化但可操作的历史会话入口。模块不能抢占问答框和经典问题卡片的视觉焦点，同时需要支持用户查看更多历史会话。

## 范围

- 删除左侧导航中的“最近会话”标题和会话列表。
- 在问答首页右侧增加独立的最近会话栏。
- 使用现有会话数据和现有历史问答跳转逻辑，不改变后端接口。
- 不调整问答框、经典问题卡片和证据评估报告的业务内容。

## 桌面端布局

- 问答首页主体采用“问答内容 + 右侧窄栏”的布局。
- 右侧栏建议宽度约为 160–180px，根据可用空间自适应。
- 右侧栏无背景色、无外框、无阴影，通过留白与浅灰蓝文字建立层级。
- 标题“最近会话”和会话文字均小于问答主体字号。
- 会话条目悬停时仅轻微加深文字或增加极浅的悬停底色。
- 单条会话标题保持一行，溢出时显示省略号；`title` 属性提供完整标题。

## 展开与收起

- 默认显示最近 3 条会话。
- 当会话数量超过 3 条时，在列表下方显示“查看更多历史”按钮和向下箭头。
- 点击后在原栏内向下展开完整历史列表，按钮变为“收起历史”并显示向上箭头。
- 展开列表设置最大高度；内容超过最大高度时在模块内部滚动，避免无限撑高页面。
- 会话数量不超过 3 条时，不显示展开按钮。
- 点击任一会话后沿用当前跳转逻辑，进入对应历史问答。

## 页面状态与响应式规则

- 空白问答首页和已有回答页面均展示最近会话栏。
- 打开证据评估报告时自动隐藏最近会话栏，将横向空间交给报告面板。
- 在空间不足的中等宽度页面，右侧栏收为“最近会话”入口按钮，点击后显示轻量列表。
- 手机端不固定占用问答区域；历史会话通过移动端入口查看。

## 组件与数据边界

- 新建独立的 `RecentConversationsPanel` 组件负责展示、展开、收起和选择会话。
- 会话数据继续由导航领域的数据源提供，避免维护两套历史数据。
- 问答页面负责决定面板是否展示，并将会话选择事件交给现有路由跳转逻辑。
- 左侧导航不再读取或渲染最近会话数据。

## 可访问性

- 展开按钮提供 `aria-expanded` 状态。
- 会话按钮和展开按钮支持键盘操作。
- 省略的标题通过 `title` 提供完整内容。
- 浅色文字仍需满足可读性，不使用真正的透明模糊文字。

## 测试与验收

- 左侧导航源码不再包含“最近会话”区域。
- 问答首页默认只显示 3 条会话。
- 超过 3 条时可以展开和收起，3 条以内不出现展开按钮。
- 点击会话能够沿用现有路由打开历史问答。
- 证据评估报告打开时，右侧栏隐藏。
- 桌面宽屏、中等宽度和手机宽度均不遮挡问答输入区域。
- 完整自动化测试和生产构建通过，并进行浏览器页面检查。

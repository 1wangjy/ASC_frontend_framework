# ASC 文献管理读者型统计卡片设计

日期：2026-08-03  
状态：待用户书面确认后实施

## 目标

将文献管理页顶部统计卡片从后台处理状态改为普通用户容易理解、能够辅助文献检索的馆藏统计，并保持四张卡片均以数字作为主要内容。

## 四项统计

1. `文献总数`：当前文献库全部记录数量。
2. `专家精选`：`expertSelected` 为真的文献数量；精选只表示资料筛选结果，不表示文献评分。
3. `近年文献`：出版年份处于“当前年份向前追溯三年（含当前年份）”窗口内的文献数量。当前年份为 2026 年时，统计范围明确为 `2023–2026`。
4. `学术论文`：文献类型为期刊论文或会议论文的合计数量，对应类型值 `journal` 与 `conference`。

## 展示文案

- 文献总数：小字 `随文献库实时更新`。
- 专家精选：小字 `高质量研究源`。
- 近年文献：小字动态显示年份范围，例如 `2023–2026 年收录`。
- 学术论文：小字 `期刊论文 + 会议论文`。

不再显示 `完成解析`、`进入 QA 索引` 或 `覆盖年份` 卡片。后台仍可保留解析、索引等数据字段，但它们不在文献管理首页作为统计项展示。

## 计算规则

- 统计函数接收文献数组和可选的当前年份；页面默认使用浏览器当前年份。
- 近年起始年份为 `currentYear - 3`，结束年份为 `currentYear`，两个端点均包含。
- 年份缺失或不是有效数字的文献不计入近年文献。
- 类型比较使用现有稳定类型值；只统计 `journal`、`conference`，图书、标准、专利等不计入学术论文。
- 空文献库时四项数量均为 `0`，近年范围仍根据当前年份显示，避免卡片文案跳动。

## 视觉规则

- 延续当前四卡等宽布局和响应式规则。
- 四张卡片的主值均为数字，字号一致，不再用年份范围长文本占据主值位置。
- 年份范围仅放在第三张卡片的小字说明中。

## 验收标准

- 2026 年环境下，近年文献统计范围为 2023、2024、2025、2026。
- 当前演示数据中 2023、2024 两篇文献计入近年文献，因此显示数量 `2`。
- 当前演示数据中四篇 `journal` 与零篇 `conference` 合计为学术论文数量 `4`。
- 页面不再出现 `近三年文献`、`覆盖年份`、`完成解析` 或 `进入 QA 索引`。
- 全部自动测试、生产构建及桌面端/窄屏页面检查通过。

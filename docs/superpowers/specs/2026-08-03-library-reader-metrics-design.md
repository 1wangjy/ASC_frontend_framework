# ASC 文献管理读者型统计卡片设计

日期：2026-08-03  
状态：待用户书面确认后实施

## 目标

将文献管理页顶部统计卡片从后台处理状态改为普通用户容易理解、能够辅助文献检索的馆藏统计，并保持四张卡片均以数字作为主要内容。

## 四项统计

1. `文献总数`：当前文献库全部记录数量。
2. `专家精选`：`expertSelected` 为真的文献数量；精选只表示资料筛选结果，不表示文献评分。
3. `学术论文`：文献类型为期刊论文或会议论文的合计数量，对应类型值 `journal` 与 `conference`。
4. `专业资料`：除期刊论文与会议论文以外的其余文献数量，包括专著、标准、专利、学位论文和其他专业资料。

## 展示文案

- 文献总数：小字 `随文献库实时更新`。
- 专家精选：小字 `高质量研究源`。
- 学术论文：小字 `期刊论文 + 会议论文`。
- 专业资料：小字 `专著、标准、专利等`。

不再显示 `完成解析`、`进入 QA 索引`、`覆盖年份` 或滚动年份范围卡片。后台仍可保留解析、索引等数据字段，但它们不在文献管理首页作为统计项展示。

## 计算规则

- 类型比较使用现有稳定类型值；只统计 `journal`、`conference` 为学术论文。
- `professionalResources = total - academicPapers`，因此没有类型或使用其他类型值的文献也计入专业资料。
- 学术论文与专业资料互不重叠，两项合计始终等于文献总数。
- 空文献库时四项数量均为 `0`。

## 视觉规则

- 延续当前四卡等宽布局和响应式规则。
- 四张卡片的主值均为数字，字号一致，不再用年份范围长文本占据主值位置。
- 第三、第四张卡分别展示学术论文与专业资料，使馆藏构成一目了然。

## 验收标准

- 当前演示数据中四篇 `journal` 与零篇 `conference` 合计为学术论文数量 `4`。
- 当前演示数据中一篇 `book` 计入专业资料，因此显示数量 `1`。
- 页面不再出现 `近三年文献`、`近年文献`、`覆盖年份`、`完成解析` 或 `进入 QA 索引`。
- 全部自动测试、生产构建及桌面端/窄屏页面检查通过。

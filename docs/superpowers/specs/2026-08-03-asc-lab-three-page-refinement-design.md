# ASC LAB 三页前端优化设计规格

## 1. 目标与范围

本轮只修改 `frontend` 中已存在的 ASC LAB 新界面，优化以下三个页面：

1. QA 首页：精简问答控制项，把四张快捷卡改为耐火材料问题分类与示例问题。
2. 文献管理：把搜索流程改成“年份分区 + 关键词 + 类型”的快速检索，并精简文献详情。
3. 知识图谱：当前页面只保留图谱启动入口；启动后进入带节点搜索和精准定位能力的图谱工作区。

本轮不修改后端，不恢复旧五步工作流，不删除旧源码，不调整数据平台和专业模型页面。

## 2. 设计基线

- 沿用当前 ASC LAB 的深蓝侧边栏、冷白背景、蓝色主按钮、细边框和紧凑科研产品风格。
- 页面背景保持冷灰白 `#f3f7fb`，内容表面保持纯白 `#ffffff`。
- 不引入新的渐变、大面积阴影、装饰性标签或营销式文案。
- 组件圆角、字体、图标线型和交互反馈继续使用现有设计令牌。
- 桌面端优先保证 1366px 及以上宽度；小屏沿用现有侧边栏抽屉和内容纵向排列方式。
- 本轮属于既有设计系统内的小范围改版，已采用用户确认的浏览器线框图，不新增位图视觉资产。

## 3. QA 首页

### 3.1 页面结构

保留当前三段结构：平台顶栏、居中的问答主区域、回答后出现的证据评估侧栏。首页空状态继续使用：

- 标题：`今天想研究什么？`
- 说明：`围绕耐火材料配方、工艺、组织结构、服役性能与失效机理提出问题`
- 大型问题输入框
- 一行四张问题引导卡

删除顶栏右侧重复的“本体增强已启用”状态，删除侧边栏底部“知识库状态 / 本地知识库演示模式”。证据评估报告和最近会话保持不变。

### 3.2 问答控制项

首页不要求用户上传文件，删除“文件”按钮、附件提示和相关本地状态。ASC 文献库由后端统一维护，因此删除知识库选择器，页面默认使用 ASC 文献库。

保留并明确以下控制项：

| 控制项 | 可选值 | 默认值 |
| --- | --- | --- |
| 模型 | `DeepSeek · V4 Flash`、`DeepSeek · V4 Pro`、`通义千问 · Qwen 3.7 Plus`、`通义千问 · Qwen 3.7 Max`、`ASC Local · V1.0` | `DeepSeek · V4 Flash` |
| 框架 | `Hybrid RAG`、`NEXUS` | `Hybrid RAG` |
| 推理 | `Auto`、`CoT`、`ToT` | `Auto` |
| 本体增强 | 开 / 关 | 开 |

只展示国内模型，模型文案统一采用 `LLM · Version` 格式。

框架和本体增强存在联动：

- `Hybrid RAG` 下，本体增强允许手动开关。
- 切换到 `NEXUS` 时，本体增强自动开启并锁定，控件以禁用态显示。
- 从 `NEXUS` 切回 `Hybrid RAG` 后恢复手动切换能力，保持“开”作为当前值。

### 3.3 四类问题引导卡

四张卡片继续原封不动地占用当前快捷卡区域：桌面端一行四列、等宽、间距 12px、高度约 76px、40px 浅蓝图标容器、白色背景和现有边框颜色。不得把卡片变成大尺寸功能面板。

分类与后端问题集的映射如下：

| 前端分类 | 后端问题集来源 | 默认示例问题 |
| --- | --- | --- |
| 材料基础与体系设计 | 耐火材料基础；复相材料的组分结构设计 | ASC 各组分分别起什么作用？ |
| 制备成型与工艺控制 | 耐火材料的合成制备成型 | 加水量如何影响浇注料流动性？ |
| 性能测试与表征分析 | 性能测试；表征分析 | 热震性能应采用哪些指标评价？ |
| 服役行为与损毁机理 | 服役机制、损耗机理 | 氧化与渣蚀如何耦合导致损毁？ |

每张卡显示分类标题和一条当前示例问题。右侧使用小型刷新图标，只刷新该分类的问题；不设置全局“换一批问题”按钮。

交互规则：

- 每次进入首页时，四个分类分别从自己的问题池随机显示一条问题。
- 点击单张卡的刷新图标时，阻止卡片点击事件，只替换该分类问题；若问题池只有一条则保持不变。
- 点击卡片主体把当前示例问题填入输入框，不自动发送，用户仍可编辑。
- 移动端允许两列或一列重排，但不得横向溢出。

### 3.4 QA 状态与证据报告

发送问题、加载状态、结构化回答、行内引用和证据评估侧栏沿用当前交互。选择模型、框架、推理方式和本体增强后，设置值在回答完成后继续保留。空问题不发送。

## 4. 文献管理

### 4.1 页面目标

文献管理用于按 DOI、标题、作者、年份、类型、摘要和关键词检索后端文献记录。统计卡和文献表格继续保留；页面重点从“多条件后台管理”调整为“快速找到一篇记不清标题的文献”。

### 4.2 快速检索区

搜索框占据工具栏主宽度，提示文案为：

`搜索标题、DOI、作者、摘要或关键词…`

搜索字段包括标题、DOI、作者、期刊、摘要、关键词和领域标签。搜索忽略大小写，并对首尾空格进行归一化。

工具栏只保留：

- 年份分区：`全部`、当前数据中的精确年份、`更早`。
- 文献类型：全部、期刊论文、会议论文、手册/图书、专利。
- 清除条件。

年份分区显示为紧凑的横向按钮组；年份按新到旧排列。`更早`匹配早于当前显示年份列表最末年份的记录。关键词、年份和类型采用 AND 逻辑。

工具栏下方显示当前有效条件和结果数量。例如：`2024 ×`、`热震 ×`、`共 6 条结果`。点击条件上的关闭图标只清除该条件。

用户只记得“关键词 + 最近年份”时，应先点击年份，再输入关键词，表格立即只显示同时满足两个条件的条目。

### 4.3 文献表格与分页

表格保持数据表布局，不改成卡片库。核心列为：文献标题、DOI、作者、年份、类型、领域标签、专家评分、处理状态和更新时间。

- 表头在表格内部滚动时保持固定。
- 选中行使用当前浅蓝底和左侧蓝色标识。
- 默认每页 20 条，可切换 20 / 50 / 100 条。
- 分页包含首页、上一页、页码、下一页。
- 筛选条件变化后自动回到第一页。
- 当前页因筛选变空时，自动校正到有效页。
- 无结果时显示“没有符合条件的文献”和清除筛选操作。

### 4.4 文献详情

右侧详情只承担“快速理解文献内容”的职责，显示：

1. 文献标题。
2. 摘要全文。
3. 与该摘要对应的关键词。

删除 PDF 封面、作者年份重复摘要、元数据列表、处理流水线、切片预览和“加入 QA 证据库”按钮。详情侧栏可以关闭；在 1180px 以下以右侧抽屉显示。

导入 DOI、批量导入、上传文献按钮继续作为前端交互演示保留，后续由后端接入真实数据服务。

## 5. 知识图谱

### 5.1 两段式结构

知识图谱采用用户确认的两段式设计：

1. ASC LAB 的 `/knowledge` 页面只展示一个图谱入口卡，主操作为 `打开知识图谱`。
2. 点击后通过统一的启动函数取得跳转地址，再进入图谱工作区。

删除当前“材料体系 / 物相与反应 / 性能关系”等概览卡和标签页，不在入口页重复展示图谱内容。

### 5.2 启动接口与前端演示

前端定义单一接口边界：

```js
launchKnowledgeGraph(): Promise<{ redirectUrl: string, graphSessionId?: string }>
```

正式接入时，该函数调用后端启动 API。密钥只保存在服务端，前端不拼接或保存 API 密钥。前端只接受 `http://`、`https://` 或当前站点内部路径；无效地址显示错误，不执行跳转。

为了让当前纯前端版本可直接展示完整流程，在没有配置启动 API 时使用本地图谱演示地址 `/knowledge/explorer`。配置后端启动 API 后，入口页面和按钮不变，只替换启动函数的数据来源。

点击后的状态：

- 请求中：按钮显示 `正在打开…` 并禁用重复点击。
- 成功：使用返回的 `redirectUrl` 在当前标签页跳转。
- 失败：入口卡下方显示简短错误和“重试”，页面不空白。

### 5.3 图谱工作区

本地演示页 `/knowledge/explorer` 代表 API 跳转后的目标界面，并作为后端图谱页面的交互合同。其首屏结构为：顶部节点搜索区、中央图谱画布、右侧节点详情。

节点搜索框固定在工作区顶部，提示文案为：

`搜索节点名称、别名或节点 ID…`

搜索结果必须返回并展示：

```js
{
  nodeId: 'material:sic',
  label: 'SiC',
  type: '原料',
  aliases: ['碳化硅']
}
```

同名节点用类型和稳定 `nodeId` 区分。键盘上下键移动结果，Enter 定位，Esc 关闭结果列表；鼠标点击结果具有相同行为。

选择结果后执行：

```js
focusNode(nodeId)
```

可观察结果必须同时包括：

- 目标节点移动到画布中心。
- 自动缩放到可读比例。
- 目标节点出现蓝色高亮环。
- 与目标直接相连的边和节点增强显示，其余内容降低透明度。
- 右侧节点详情同步显示名称、类型、别名、关系数量和证据文献数量。
- 左下角短暂显示“已定位：节点名称”。

无匹配结果显示“未找到节点，请尝试名称、别名或节点 ID”，不得改变当前画布位置。图谱工作区提供“重置视图”和“全屏”按钮。

## 6. 组件与数据边界

建议保持现有 Vue 3 结构并拆分为以下职责：

- `qaDemoModel.js`：QA 设置、框架与本体联动。
- `questionGuideModel.js`：四类问题池、页面初始化和单卡刷新。
- `QuestionComposer.vue`：模型、框架、推理和本体增强控件。
- `TaskShortcuts.vue`：四张问题分类卡及单卡刷新。
- `libraryModel.js`：搜索归一化、年份分区、AND 筛选和分页。
- `LibraryToolbar.vue`：搜索、年份按钮组、类型和有效条件。
- `DocumentTable.vue`：固定表头、选择行和分页。
- `DocumentDetails.vue`：标题、摘要和关键词。
- `knowledgeGraphLauncher.js`：图谱启动地址获取与地址校验。
- `graphExplorerModel.js`：节点搜索、结果选择和精准定位状态。
- `KnowledgeView.vue`：唯一图谱入口。
- `KnowledgeExplorerView.vue`：本地图谱工作区演示。

页面组件只负责显示和事件绑定；可测试的随机、筛选、分页、联动和搜索定位逻辑放入纯 JavaScript 模型。

## 7. 可访问性与响应式

- 所有图标按钮提供中文 `aria-label`。
- 选择器、搜索框、开关、分页和搜索结果支持键盘操作。
- 禁用的本体增强控件同时设置 `disabled` 和可理解的说明。
- 焦点样式继续使用全局蓝色轮廓。
- `prefers-reduced-motion` 下关闭卡片位移和图谱平移动画。
- 760px 以下，问答控制项允许换行；文献表格横向滚动；图谱详情改为底部或右侧抽屉。

## 8. 测试与验收

纯模型测试必须覆盖：

- 国内模型列表和默认模型。
- `NEXUS` 自动开启并锁定本体增强。
- 首页初始化四类问题、单卡刷新不影响其他三卡、点击问题只填充不发送。
- 文献搜索包含摘要和关键词，年份与关键词采用 AND 逻辑。
- 年份分区、清除单项条件、20 / 50 / 100 分页和页码校正。
- 图谱启动地址校验、请求失败状态。
- 节点名称、别名和 `nodeId` 搜索。
- 选择结果后精准设置 focused node，并保留无结果时的原视图。

页面验收路径：

1. 进入 QA 首页，确认四卡单行排列和控制项精简。
2. 刷新一张问题卡，确认其他三张不变；点击示例问题，确认只填入输入框。
3. 切换 `NEXUS`，确认本体增强自动开启并锁定；切回 `Hybrid RAG` 后恢复可切换。
4. 打开文献管理，选择年份并搜索摘要或关键词，确认只显示交集结果。
5. 切换分页数量、选中文献，确认右侧只显示标题、摘要和关键词。
6. 打开知识图谱入口，经过启动函数进入图谱工作区。
7. 搜索 `SiC`，选择 `material:sic`，确认画布居中、缩放、高亮和详情同步。
8. 分别检查桌面宽度和约 390px 移动宽度，无内容裁切、错误换行或横向页面溢出。

生产构建必须成功，现有测试不得回退。最终浏览器截图应与用户确认的三页设计保持相同的信息层级、颜色、密度和交互位置。

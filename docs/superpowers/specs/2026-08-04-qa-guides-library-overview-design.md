# 首页问题卡片与文献概览精简设计

## 目标

降低问答首页经典问题区域和文献管理页顶部统计区域的视觉重量，让用户更快进入提问和文献检索主流程，同时保留必要的引导能力与馆藏概览信息。

## 问答首页经典问题

- 保留现有四个问题分类及四张横向卡片。
- 每张卡片默认只显示 1 条经典问题，不再显示 3 条。
- 保留每张卡片右上角的独立刷新按钮。
- 点击刷新后只更换当前分类的这一条问题，其他三张卡片保持不变。
- 刷新后的问题不得与刷新前相同；问题仍从该分类现有问题池中选取。
- 点击经典问题继续将其填入问答输入框，不自动发送。
- 单条问题最多显示两行，较长内容自动换行并截断，完整文本通过 `title` 提供。
- 桌面端卡片目标高度约为 120–130px，四张卡片保持等高。
- 平板端继续使用两列，手机端继续使用一列；卡片不因长问题产生明显高度差。

## 文献管理页馆藏概览

- 从文献检索主区域删除当前四个大号统计卡片。
- 在“文献管理”标题旁增加一个低强调度的“馆藏概览”按钮。
- 按钮默认只占用标题行的小块空间，不影响搜索栏、年份筛选和文献表格的首屏位置。
- 点击按钮后显示紧凑浮层，保留以下四项实时数据：
  - 文献总数；
  - 专家精选；
  - 学术论文（期刊论文与会议论文）；
  - 专业资料（专著、标准、专利等其他类型）。
- 浮层使用 2×2 的紧凑数据布局，不复用原大卡片尺寸。
- 再次点击按钮、点击组件外部或按 Esc 均关闭浮层。
- 按钮提供 `aria-expanded`，关闭后焦点返回触发按钮。
- 小屏幕浮层宽度不超过可视区域，不造成横向滚动。

## 数据与组件边界

- `questionGuideModel` 继续负责问题抽取和逐分类刷新，将每组展示数量改为 1。
- `TaskShortcuts` 只负责渲染单条问题和刷新入口，不复制问题随机逻辑。
- 文献统计仍由 `calculateLibraryMetrics` 实时计算，避免因隐藏而丢失数据能力。
- 新建独立的 `LibraryOverviewPopover` 组件，消费文献统计数组并管理打开、关闭和焦点行为。
- `DocumentLibraryView` 负责提供统计数据和放置概览入口，不再渲染原 `summary-grid`。

## 测试与验收

- 每个问题分类状态只包含 1 条当前问题。
- 刷新一个分类后，该问题改变，其他分类保持不变。
- 四张问题卡片桌面端横向等高，长问题不撑高卡片。
- 文献页默认看不到四个大统计框。
- 点击“馆藏概览”可看到四项实时数据，并可再次点击、点击外部或按 Esc 关闭。
- 浮层关闭后焦点回到“馆藏概览”按钮。
- 桌面、平板和手机宽度均无横向溢出。
- 完整自动化测试与生产构建通过，并完成浏览器视觉检查。

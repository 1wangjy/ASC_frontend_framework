## 限制与附加发现

1. 会话持久化当前只保存工具参数/结果摘要。刷新后read_evidence参数显示`{}`，完整结果没有恢复，不能表述为“所有工具原始详情完整保留”。该行为来自现有route.js会话投影和policy.summarizeArgs白名单，本轮未改保存策略。
2. A第5轮宽泛历史查询`页面验收 UI-A73 SiC含量 保温时间 3小时`命中0条，模型凭可见对话正确回答最新3小时；这不算历史工具召回成功。后续精确关键词正向对照命中5条。长查询匹配与字段分散记录的检索策略仍有改善空间。
3. 尚未调用任何工具时，界面曾出现“正在执行工具，等待知识服务返回回答”的通用提示，文案不能准确反映纯模型等待阶段。
4. 本轮没有中途刷新正在运行的请求，没有验收后台断点续传、浏览器关闭重开、并发性能或科学回答质量。

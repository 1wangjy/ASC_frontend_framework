## 已实施

- `POST /api/agent/sessions/:id/stop`：主动取消当前任务；重复停止安全返回。前端先请求后端，再中止本地连接。接口最多等待 8 秒；失败显示错误，不谎报后端已停止。
- 会话详情新增可选 `activeTurn`（问题、范围、本轮起始事件 ID）。刷新/历史恢复重新连接当前轮，不重发问题或模型请求。
- 超时/停止后清理未完成工具状态；停止标记及超时错误正确恢复到历史。超时后的空重连不会清除原错误或重新执行。

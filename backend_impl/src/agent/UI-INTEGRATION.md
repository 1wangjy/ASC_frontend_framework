## 历史会话输入框裁切修复（2026-10-08）

用户实际浏览器截图确认：首次回答后，Agent 输入框不可见。原因是父级 `workspace--history` 使用固定高度与 overflow:hidden，而 Agent 的状态栏、消息与内置输入框总高度超出该容器；内部滚到答案末尾也无法看到被外层裁掉的输入框。此前建议单纯滚动页面不充分。

仅在 Agent 模式给 AscQaView 工作区增加 `workspace--agent` 布局：外层 height:auto、min-height:0、overflow:visible。保留 Agent 消息区域的有限高度和内部滚动，输入框随整个页面可达；不承诺固定在视口底部。选择器优先级高于原窄屏 history 高度规则；兼容知识对话的固定高度与深度研究不变。

新增 CSS 契约测试与历史恢复组件断言，先验证两项失败，再验证修复后通过。最新前端 Agent 回归 75 项通过、2 项真实服务测试默认跳过，构建通过。未再次调用模型、未改动会话存储。CSS/组件测试不是像素或真实窄屏验收，用户刷新后应确认当前会话可看到输入框并续问。

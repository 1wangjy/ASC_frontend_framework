## 9 个工具盘点

| 工具 | 作用 | 本轮覆盖 | 尚未证明的部分 |
| --- | --- | --- | --- |
| kg_list | 查询可用图谱与项目 | 真实 API 目录查询 | 多用户目录权限，批量性能 |
| kg_graph | 查询指定图谱节点及关系 | 真实 API 读取，已有过滤/大小边界模拟回归 | 大图上游分页及并发性能 |
| kg_search | 返回知识服务成文答案与引用 | 真实 API 固定问题，答案/引用/绑定原样比较，范围拒绝回归 | 主 Agent 自主选择工具的完成率 |
| rag_search | 使用知识 API 的检索模式返回片段 | 真实 API 固定问题，不发布服务答案 | 独立文献服务和全文读取 |
| predict | 通过预测 API 返回性能数值 | 模拟成功、错误参数、HTTP 错误、非 JSON、断网 | 真实预测服务本轮无监听，部署待验收 |
| recipe_optimize | 通过 API 优化配方 | 盘点注册及 schema，既有参数/预算回归 | 本轮未执行真实优化，也未新增优化服务模拟效果测试 |
| web_browse | 读取白名单网页 | 既有白名单、重定向、响应大小等模拟回归 | 本轮未执行外部网页真实抓取 |
| search_history | 检索当前会话当前主题历史 | 已保存会话真实读取后调用本地工具，主题重置隔离和无会话拒绝 | 多用户账号授权并非本轮测试范围 |
| read_evidence | 按 ID 读取本轮 API 已返回片段 | 两次真实 API 片段完整读取、未知 ID 拒绝、跨轮与非法 ID 模拟回归 | 不是整篇论文读取，无科学支持度判定 |

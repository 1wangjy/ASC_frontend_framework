# 知识服务原答案接入记录（2026-10-08）

## 本轮范围

按用户最新要求，不评价或优化科学答案质量，不继续草稿支持度实验。主 Agent 保留工具选择、多轮历史与条件管理，知识工具成功返回 `final_answer` 后直接发布其原始文本、完整 `references` 和 `citation_bindings`。服务答案不标记为 Agent 已核验。

旧智能会话调用 `/multi-discussion/chat`，Agent 工具调用 `/graphrag/cod-query`：这里的兼容指本次工具返回内容不被 Agent 改写，不保证不同接口生成文字相同。未修改知识服务检索或内部核验参数。

## 实现

- `tools/kgSearch.js` 保留独立的完整发布数据，旧紧凑工具投影不变。
- `tools/index.js` 转发服务端控制的回答模式，完整发布数据不受旧 24000 字符投影截断影响。
- `serviceAnswer.js` 做范围一致性与格式检查、引用展示映射，不做语义判断。
- `loop.js` 成功后直接结束本轮，服务失败/没有答案时不把模型自行生成的材料结论作为替代答案。
- `route.js` 默认原答案模式，并持久化服务引用及绑定；`AGENT_ANSWER_MODE=evidence_draft` 可运维回退。客户端不能覆盖模式。
- 前端状态明确为“知识服务原答案 · Agent 未二次改写”；引用原始文本可展开，历史恢复保留原答案空白。
- 单条答案传输上限为 64000 字符、完整发布 JSON 为 256000 字符。超过上限明确失败，不静默截断。原工具权限、范围、调用预算、超时和异常保护保留。

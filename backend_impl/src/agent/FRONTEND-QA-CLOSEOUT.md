## 归类与修复

- 旧测试仍要求旧 Tab 文案、默认 single、完成报告资格、右侧重复的新建/退出按钮和图谱完成后自动跳转。这些断言与当前 Git 代码不一致；按当前行为更新，不恢复旧入口。
- workflow 测试桩缺少任务监视器 `start/stop`；补齐生命周期，显式选择深度研究，检查启动刷新与项目切换。项目名称断言改为当前项目栏，避免误读任务列表。历史兼容测试显式进入原知识对话；主 Agent 的历史和锁定仍由 Agent 组件测试覆盖。
- **真实缺陷一**：`AscQaView.vue` 的 reset 使用默认 multi 状态，使深度研究历史问题和返回首页走错入口。现在只清空回答，保留所选模式及模型/推理设置。
- **真实缺陷二**：项目选择允许图谱构建完成，但 `qaApiAdapter.js` 仍强制模拟 ID。现在无模拟 ID 时查询服务端项目并复用现有图谱资格规则；不伪造模拟 ID。已有模拟 ID 的对应关系校验、项目与图谱身份校验、响应范围校验均保留。
- 适配器旧报告门禁测试改为当前项目/图谱范围测试，保留完整回答字段及引用解析回归。新增 3 项针对无模拟图谱、未完成图谱和模拟范围不匹配的回归。

业务源码仅修改 `src/views/AscQaView.vue`、`src/features/qa/qaApiAdapter.js`。测试修改位于 `tests/`；后端业务代码未改。修改前测试副本保留在本轮留档目录的 `legacy-before/`。

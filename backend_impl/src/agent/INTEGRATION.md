# Agent 真实后端联调记录

日期：2026-10-08。范围：一个真实问题与一次追问的后端闭环，不是批量质量评测或最终前端验收。

## 配置与入口

- 模型：`deepseek-flash`，已通过服务模型目录接口确认可用；本轮不是本地微调模型接入验收。
- 知识 API：`http://127.0.0.1:5001`，使用项目中既有 Python 知识服务。本轮没有修改该服务代码，也不代表已对接李铭豪的新部署。
- Agent：`http://127.0.0.1:3001/api/agent`，独立本机入口，避免全平台原生数据库模块影响联调。
- API 范围：`proj_65ac6094e268 / nexus_2bdcb8bbccb04ea5`，通过图谱目录确认。Agent 不读取知识服务的图谱文件。
- 本后端 `.env` 通过 `AGENT_ENV_FILE` 引用原项目现有配置文件，未复制密钥；不得将密钥放入报告或聊天。
- 启动：在 `backend_impl` 执行 `npm run agent:start`；检查：`npm run agent:check`；真实两轮：`npm run agent:smoke`。

## 同一真实样例

首问：请检索当前图谱及文献，说明 SiC 与抗氧化性能有哪些关联，并给出本轮证据引用。

追问：那在 1500℃ 空气气氛下呢？请核对原文条件，不足时说明缺口。

本轮固定问题与范围，没有固定检索返回或模型随机性，因此不是单因素成本消融实验。

## 失败也留档

1. `data/agent/integration/smoke-1791436516056.json`：两轮均达到约 300 秒时限。存在多次重复检索、大结果上下文导致证据 ID 可读性不足的风险；不能仅凭这次运行确定唯一原因。
2. `data/agent/integration/smoke-1791436906766.json`：首问 153479 ms，引用检查通过；追问 198123 ms，工具额度耗尽直接结束，检查状态 incomplete。首问末尾也出现截断迹象，旧适配器未保留 length 状态，因此该首问不能当作完整回答质量通过。该旧报告的 followup_skipped 字段错误，实际执行了两轮；后续脚本已修正。

## 本阶段修复

- 模型收到最多 5 条证据预览及限幅路径/摘要，完整 API 片段仍保存于本轮证据台账和会话。超大上下文的兜底保持有效 JSON。
- 每轮知识检索默认最多 2 次，总工具预算保持 8 次；超额调用明确拒绝并审计。
- 最后一轮模型调用或工具额度用完后的模型调用不提供工具，只用于整理已有结果和缺口，不扩大工具执行权限。模型仍请求工具时安全标记未完成。
- 默认简洁回答，避免冗长列举无关引文或服务生成机理；保留真实 finish_reason，token 截断不算成功。
- 真实脚本保存问题、回答、工具耗时、检查结果、会话 ID、模型配置、代码指纹及进程级 token 汇总。知识服务内部 token 与账单费用尚未纳入，不能把该汇总当作完整费用。

离线回归：94 项通过；覆盖配额、收尾、截断、配置优先级、证据台账、历史继承、HTTP/SSE 和超时等。离线结果不是 94 次真实问答完成率。

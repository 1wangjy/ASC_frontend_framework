# T3 知识 API 等待与计时

更新：2026-10-09。本阶段只改执行可见性与计时，不优化回答质量，不改知识服务原答案、引用或绑定。

## 1. 已确认的接口边界

目前 Agent 的 `kg_search` / `rag_search` 调用 `POST /api/graphrag/cod-query`。检查现有知识服务路由后确认：处理函数同步等待 `cod_graphrag_answer()`，完成后一次返回 JSON；这条调用链未提供处理中任务 ID、阶段流或远端取消接口。

这不是对李铭豪系统其他版本的断言，也不表示已经与本人完成协议确认。现有 SSE `: ping` 仅维持连接，不是检索进度；其他业务的进度接口不能直接当成这次查询的进度。

## 2. 本阶段实现

- 模型请求开始/结束发出 `model_status`，工具开始携带 `startedAt`，工具结束保存 `ms` 与 `finishedAt`。
- 前端显示当前工具名和已等待秒数；超过 30 秒提示“尚未返回，不代表失败”。不编造阶段或百分比。
- `done.timing` 保存本轮总耗时、模型请求、知识工具、其他工具和本端剩余处理耗时。正常、超时、停止均收尾记录。
- 分段耗时与工具起止时间保存到会话，完成后刷新仍可查看；执行中刷新重放同一轮，不重新检索、不重置开始时间。
- 前端计时器只在执行中运行，结束/卸载清理。旧会话没有新增计时字段时不补造零值。
- 停止提示明确：本端已停止等待，远端计算是否取消未知。未完成工具不计为成功。
- 主动停止后最多等待 1 秒接收服务端收尾帧，保留停止耗时；连接异常时兜底中断，不一直锁住输入。实际测试曾发现原先立即断流漏收计时帧，已据此修复。
- 顺带修复历史工具参数摘要的对象兼容：之前服务端保存对象、前端只接受字符串，刷新后误显示“无参数”；现在展示已有安全摘要，不保存额外原始参数。

计时口径：结束后的时长来自服务端单调时钟。页面等待秒数采用本地部署的开始时间与当前墙钟，仅表示已经等待多久，不预测剩余时间。`knowledgeToolMs` 包含范围解析、网络请求、上游处理和本端结果适配，**不能称作纯知识检索计算时间**。本端没有上游分段日志，无法拆分数据库检索、上游模型、网络传输；token 仅计主模型实际报告值，不代表知识服务完整用量或费用。

新增事件不改变 `final` 的答案字段；仍按 `knowledge_service` 原样发布服务答案、引用和绑定。

## 5. 真实同题结果与异常复验

问题：**ASC 材料中 SiC 主要有哪些作用？请通过知识检索回答。**

项目 `proj_65ac6094e268`，图谱 `nexus_2bdcb8bbccb04ea5`，主模型 `deepseek-flash`，每次新会话，`maxSteps=6 / maxTools=8 / timeoutMs=300000`，顺序执行、没有并发。本次三轮实际都选择 `kg_search`，查询摘要一致，`topK=6`。模型选择工具仍是动态过程，未来重复不保证自动产生相同参数。

| 样本 | 入口 | 模型请求 | 知识工具 | 本轮总耗时 | 返回引用 |
| --- | --- | --- | --- | --- | --- |
| 1 | 真实页面，含执行中刷新 | 0.899 秒 | 127.905 秒 | 128.809 秒 | 16 |
| 2 | 同配置 HTTP | 1.080 秒 | 114.914 秒 | 115.999 秒 | 16 |

三轮均完成：**3/3**，总耗时中位数 **128.809 秒**，范围 **115.999–137.722 秒**。这只是单题小样本，不代表一般完成率、并发能力、速度提升或科学正确率；没有改造前相同条件的三轮对照，不计算提速比例。

主模型实际报告 token 分别为 3581、3640、3625；不包含知识服务内部模型，因此不换算整个流程费用。HTTP 样本的 `clientRequestMs` 包含接收整轮 SSE 后读取保存会话的时间，不能当成纯网络传输耗时或页面渲染耗时。

三轮 SSE 留档均验证：`final.text`、`service_references`、`citation_bindings` 与成功知识工具的原始发布对象一致。浏览器第一轮通过 **完成后的 SSE 重放**补齐原始帧和 token 档案，没有重新执行查询。见 `baseline.json`、`sample-2.sse`、`sample-3.sse` 以及 `archive-940e8454-57e4-49d2-bf87-aa12d5042243-summary.json`。

异常复验不纳入上述三次完成率：

- 故意设置 50ms 回合预算：真实 HTTP 返回 `turn_timeout`，保存总耗时 59ms、模型请求 57ms，没有发布替代答案；知识工具尚未执行。记录 `real-short-timeout.sse` 和对应会话。
- 主动停止第一次：保存本轮 31.357 秒、知识工具 30.462 秒；发现立即断流漏收终帧的 UI 问题。
- 修复后主动停止：本轮 47.368 秒、知识工具 46.151 秒，页面**不刷新即可**显示停止耗时，输入区恢复，工具显示“已停止”而非成功；随后历史仍保存相同计时。记录 `archive-ee27b5d6-d003-4081-a283-c9e097e020f8-session.json` 和 `stopped-with-timing.jpg`。

另外修正状态误导：主动停止不再显示顶部“执行失败”；模型响应结束后等待工具时，不再把已结束的推理内容标成“思考中”。上述停止耗时仅表示本端已花费时间，**仍未确认远端计算被取消**。

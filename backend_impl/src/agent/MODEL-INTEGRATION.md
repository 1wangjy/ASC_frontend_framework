# Agent 模型切换与本地配置

日期：2026-10-08。对应任务 T2 的模型选择子阶段，不代表本地微调模型部署、科研效果、多模态或全部四项任务完成。

## 已实现

数据流：页面选择 `modelId` → 后端读取允许列表 → 校验配置 → 调用对应 provider → SSE 返回实际模型 → 按轮保存至历史。

- `models.js`：从服务端 `AGENT_MODELS_FILE` 读取最多 15 个额外模型，默认模型继续复用现有环境配置。目录接口仅返回 ID、标签、类型、模型名和配置状态，不返回 URL、密钥或密钥环境变量名。
- `GET /api/agent/models`：前端模型目录。`POST /api/agent/stream` 新增可选 `modelId`；不提供时使用 `default`。客户端不能通过此入口提交任意模型 URL、凭据或 provider。
- `model_selected` 事件：返回本轮实际配置 ID 与模型名；会话的 assistant 消息保存 `model: {id, name}`。旧消息没有模型信息时不补造记录。
- 智能会话主输入新增模型选择、刷新模型与本地配置说明入口。运行中不能改本轮模型；下一轮切换不清空当前会话；断线重放沿用原运行结果，不重新调用新选择的模型。
- 未部署或配置不全的模型禁选，后端仍独立拒绝调用。配置完成只表示必要参数齐全，不等于服务在线、支持工具或图片。

## 配置方式

示例：`backend_impl/config/agent-models.example.json`。部署时复制为管理员维护的 `agent-models.json`，在本后端 `.env` 指向绝对路径：

```dotenv
AGENT_MODELS_FILE=D:/shixi/中关村学院/ASC_frontend_framework/backend_impl/config/agent-models.json
```

本机联调暂时直接引用示例文件，登记了云端 Pro 和禁用的本地模型占位项。配置文件只写 `keyEnv` 名称，真实凭据放在后端环境中，不写入 JSON、浏览器或报告。

本地服务准备好后，由管理员填写：

```json
{
  "id": "local-finetuned",
  "label": "本地微调模型",
  "kind": "local",
  "model": "实际部署的模型ID",
  "apiUrl": "http://127.0.0.1:8000/v1",
  "authMode": "none",
  "enabled": true,
  "maxTokens": 2048
}
```

地址仅为示例，当前没有声称该端口存在推理服务。无鉴权必须显式设置 `none`；需要鉴权时使用 `bearer` 并填写 `keyEnv`。本地 profile 不自动继承云端密钥。文件中的模型目录可刷新读取；环境变量更改需要重启后端。

页面入口目前是安全的配置说明，不是在线编辑、下载权重或启动 GPU 服务。与李铭豪确认实际地址、模型 ID/版本、部署设备、工具调用、SSE、usage 以及图片支持后，才能启用并做真实 Agent 验收。当前适配器依赖 OpenAI 兼容 `tools/tool_calls`，仅支持普通聊天的服务不能直接当作已完成 Agent 接入。

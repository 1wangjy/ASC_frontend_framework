# ASC Frontend Framework

ASC 前端页面项目，基于 Vue 3 和 Vite 开发。

## 环境要求

- Node.js 18+
- npm

## 安装依赖

```bash
npm install
```

## 启动项目

```bash
npm run dev
```

启动后访问：<http://localhost:3000>

## 主要目录

- `src/views/`：页面
- `src/components/`：组件
- `src/api/`：接口请求
- `src/assets/`：图片等静态资源
